# PizzaHub — Client (Next.js + TypeScript)

## Stack
Next.js App Router · TypeScript · ShadCN UI · Tailwind · Better Auth · Framer Motion · Stripe Checkout

## Install
npm install
cp .env.local.example .env.local
npm run dev

## Env keys
NEXT_PUBLIC_API_URL, NEXT_PUBLIC_APP_URL, BETTER_AUTH_SECRET, BETTER_AUTH_URL,
MONGODB_URI, DB_NAME, GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET
